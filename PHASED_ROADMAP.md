# DAO Proposal Translator — Phased Product Roadmap

## Phase 1 — MVP: Proposal Translation and Vote Guidance

### Goal
Turn complex DAO governance text into plain-English decision support for holders and delegates.

### Core features
- Proposal text input
- Source URL capture
- Plain-English summary generation
- Risk level and score output
- Impact explanation
- Recommended vote direction
- Basic governance tags such as Treasury, Governance, Community, Security

### User value
- Makes governance proposals easier to understand in under a minute
- Helps users quickly identify treasury, custody, and governance risk
- Creates a more accessible voting workflow for non-technical participants

### Success metrics
- Proposal can be understood in less than 1 minute
- Users can identify risk without reading full proposal text
- Clear vote recommendation improves decision confidence

---

## Phase 2 — Governance Context and Historical Intelligence

### Goal
Add real-world governance context so the tool is more than a text summarizer.

### New features
- Snapshot and onchain proposal fetch support
- Proposal metadata extraction (author, voting window, quorum, threshold)
- Historical proposal comparison against similar governance actions
- Similarity analysis to prior governance decisions
- DAO-specific risk scoring
- Comparison with past treasury allocation, parameter changes, and grants

### User value
- Gives users context beyond the proposal text itself
- Helps identify whether a proposal matches past governance patterns
- Makes the tool more useful for real-world governance decisions

### Success metrics
- Users can compare a current proposal to historical governance decisions
- Risk assessments improve with real DAO context
- Proposal summaries are more actionable and less generic

---

## Phase 3 — Personalized Governance Copilot

### Goal
Turn the project into a decision assistant tailored to a voter or delegate.

### New features
- Vote recommendation tuned to user preferences
- Delegate or voter profile compatibility analysis
- Proposal relevance scoring for a user’s wallet or delegate alignment
- Short, medium, and long-form summary outputs
- Governance alerting for new proposals matching watched risk factors
- Explanation of tradeoffs and key questions to ask before voting

### User value
- Helps users form a vote recommendation without reading every detail
- Makes governance participation more efficient and less overwhelming
- Works as an assistant for delegates, token holders, and contributors

### Success metrics
- Recommendation quality improves with user-specific context
- Users use the tool repeatedly as part of their governance workflow
- Alerts increase the number of proposals reviewed

---

## Phase 4 — Governance Intelligence Platform

### Goal
Expand from a single proposal tool into a DAO governance intelligence platform.

### New features
- Multi-DAO monitoring dashboard
- Risk heatmap across active governance proposals
- Treasury and governance activity trends
- Proposal sentiment and discussion monitoring
- Cross-chain governance overview
- Historical governance health analytics
- Watchlist for key DAOs, delegates, and governance policies

### User value
- Helps governance communities monitor risk and decision quality at scale
- Gives delegates and teams a real-time overview of governance activity
- Creates strategic value beyond a single voting decision

### Success metrics
- Platform supports multiple DAOs simultaneously
- Governance teams can use it to review active risk signals
- Users treat it as a governance operating layer instead of a demo

---

## Strategic Expansion Themes

The product should expand around four main themes:

1. Plain-English interpretation
2. Governance-risk detection
3. Context-aware recommendation
4. Multi-DAO governance intelligence

This keeps the identity consistent while allowing the product to scale.

---

## Recommended Product Direction

The best expansion path is to keep the core promise intact:

“Understand governance proposals fast, evaluate risk clearly, and decide with more confidence.”

Everything added after Phase 1 should be designed to make that statement more powerful, not broader in a vague way.
