# DAO Proposal Translator Demo

A polished DAO governance assistant demo designed for fast, plain-English proposal analysis.

## What it does
- Translates governance proposals into a simple summary
- Highlights the main risks and tradeoffs
- Produces a clear recommended vote direction

## Deployment
This project is built to work as a static site and can be published directly through GitHub Pages or any static hosting provider.

## Run locally
- Open the project folder in a browser, or
- Start the lightweight local server with `node server.js`
